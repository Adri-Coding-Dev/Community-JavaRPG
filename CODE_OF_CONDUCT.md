# ❤️ Código de Conducta

---

# 🌍 Objetivo

Queremos construir una comunidad:

* respetuosa,
* educativa,
* colaborativa,
* y amigable.

---

# ✅ Comportamiento Esperado

Por favor:

* respeta a los demás,
* acepta críticas constructivas,
* ayuda a quienes estén aprendiendo,
* mantén discusiones sanas.

---

# ❌ Comportamiento No Permitido

No se tolerará:

* acoso,
* discriminación,
* insultos,
* toxicidad,
* trolling,
* contribuciones destructivas.

---

# ⚖️ Revisiones de Código

Las revisiones NO son ataques personales.

Su objetivo es:

* mejorar el proyecto,
* mantener calidad,
* y ayudar a crecer técnicamente.

---

# 🚫 Aplicación de las Normas

Los maintainers podrán:

* rechazar PR,
* cerrar discusiones,
* eliminar contribuciones,
* expulsar usuarios si es necesario.

---

# ❤️ Filosofía Final

Estamos aquí para:

* construir algo increíble,
* aprender juntos,
* y disfrutar desarrollando.
